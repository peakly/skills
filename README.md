# Peakly Skills

Agent skills and guides for integrating with the [Peakly API](https://peakly.co) — Argentina's invoicing and business management platform.

## Guides

| Guide | Description |
|---|---|
| [Quick Start](agents/quick-start.md) | Authenticate and send your first invoice in minutes |

| [Concepts](agents/concepts.md) | Argentine invoicing fundamentals (AFIP, CAE, factura types) |
| [Entity Reference](agents/entities.md) | Field-level reference for Customer, Product, and Sales Receipt |

## SDK & CLI

- **TypeScript SDK:** [`@peakly/sdk`](https://github.com/peakly/peakly-sdk) — type-safe client auto-generated from OpenAPI
- **CLI:** [`peakly-cli`](https://github.com/peakly/peakly-cli) — command-line tool for Peakly

## API Reference

Base URL: `https://api.peakly.co`

Full OpenAPI spec: `GET https://api.peakly.co/openapi.json`

LLMs.txt: `GET https://api.peakly.co/llms.txt`
